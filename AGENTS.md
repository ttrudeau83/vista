# Project instructions

Use subagents as needed and verify their work.

Use CLI and MCP tools only. Do not use computer-use tools, desktop UI automation,
mouse/keyboard control, or window activation unless the user explicitly requests an exception.

Read `docs/PROJECT_BRIEF.md` before changing application behavior. Complete one
approved milestone at a time. Preserve upstream functionality and license notices.
Never commit credentials, private photo data, SDK installations, or reference clones.
Never automatically disable or uninstall the stock launcher.
